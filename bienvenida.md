# ¡Bienvenidos, estudiantes!

¡Hola y bienvenidos!

Nos alegra mucho tenerlos aquí. Este es el inicio de un camino lleno de aprendizaje, y queremos que lo recorran con curiosidad y entusiasmo.

## Los invitamos a usar Claude Code

Claude Code es un asistente de programación que trabaja directamente en su terminal y dentro de sus proyectos. Con él pueden:

- **Aprender más rápido:** pídanle que les explique código que no entienden, paso a paso.
- **Crear proyectos:** describan lo que quieren construir y colaboren con él para hacerlo realidad.
- **Encontrar y corregir errores:** compartan el problema y revisen juntos posibles soluciones.
- **Experimentar sin miedo:** prueben ideas, equivóquense y vuelvan a intentarlo.

## Un consejo

Usen Claude Code como un compañero de aprendizaje, no como un atajo. Pregunten el porqué de cada cosa, revisen lo que genera y traten de entenderlo. Así su aprendizaje será mucho más sólido.

¡Anímense a explorar, a preguntar y a crear! Estamos seguros de que van a lograr cosas increíbles.

¡Éxitos y bienvenidos!

El equipo docente
