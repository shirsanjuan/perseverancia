# Proyecto de hoy: simulación 3D del rover Perseverance en Marte

## Qué queremos

Construir, con ayuda de Claude Code, una simulación en 3D del rover **Perseverance** explorando la superficie de Marte. La actividad completa dura **60 minutos** y este documento registra todo el proceso que seguiremos hoy.

## Resultado esperado

- Una página web (`index.html`) que se abre directamente en el navegador.
- Un modelo 3D simple del rover (chasis, seis ruedas, mástil con cámara y brazo robótico).
- Un terreno marciano (suelo rojizo, rocas, cielo anaranjado).
- Controles para mover el rover y rotar la cámara con el ratón.

## Tecnología

- HTML + JavaScript con la librería **Three.js** (sin instalaciones complicadas).
- Claude Code para generar, explicar y corregir el código.

## Plan de los 60 minutos

| Minutos | Etapa | Qué hacemos |
|---------|-------|-------------|
| 0–5 | Introducción | Explicar el objetivo, el rover Perseverance y cómo usar Claude Code |
| 5–15 | Escena base | Crear la escena 3D: cámara, luces, cielo y suelo de Marte |
| 15–30 | El rover | Modelar el chasis, las ruedas, el mástil y el brazo |
| 30–40 | Movimiento | Programar el avance, el giro y las ruedas que rotan con teclado |
| 40–50 | Detalles | Agregar rocas, polvo, sombras y una cámara que siga al rover |
| 50–58 | Pruebas y mejoras | Revisar errores y ajustar con ideas de los participantes |
| 58–60 | Cierre | Mostrar el resultado final y comentar lo aprendido |

## Proceso

1. Describir a Claude Code lo que queremos en cada etapa.
2. Revisar lo que genera y probarlo en el navegador.
3. Pedir ajustes hasta que se vea y funcione como esperamos.
4. Anotar aquí lo que vayamos logrando durante la sesión.
